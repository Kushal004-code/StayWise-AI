# StayWise-AI

## StayWise AI — AI-Powered Smart Hospitality & Hotel Management Ecosystem

### Project Purpose
**StayWise AI** is a full-stack smart hospitality and hotel management ecosystem designed to modernize hotel operations and guest experiences. It combines core hotel management workflows (room inventory, reservations, role-based staff/admin management, and billing) with AI-driven capabilities including a RAG-powered Smart Concierge assistant, intelligent room recommendations, and automated guest insights.

### Technology Stack
- **Frontend:** React, Vite, TypeScript, Tailwind CSS
- **Main Backend:** Java 21, Spring Boot, Spring Security, JWT, Spring Data JPA
- **AI Backend:** Python 3.12, FastAPI, LLM Integration, Retrieval-Augmented Generation (RAG)
- **Database:** PostgreSQL 18
- **Developer Tools & Workflow:** Git, GitHub, Docker, Swagger / OpenAPI, Postman / Bruno
